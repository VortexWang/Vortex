Corrected Phase 4 qualification scope to match the restarted project decision.
The gate now requires 4 logical CPUs and 8 GiB memory plus the existing runtime,
TLS, accounting, duration, and trial evidence. Dedicated resources, an
independent link, virtualization status, and provider attestation are retained
as evidence fields but no longer block qualification by themselves.
