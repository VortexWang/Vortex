# Plan 05-02: Registration, mTLS control, reconcile and upgrade supervision

## Goal

Implement node enrollment, short-lived runtime identity, bidirectional control, config reconciliation and bounded upgrade rollback.

## Tasks

1. Implement one-time enrollment token to local key generation and CSR exchange. Keep node_id in certificate SAN, bind boot_id in the authenticated runtime handshake, enforce revocation on reconnect/renewal, and rotate certificates with old/new overlap only after validation.
2. Implement Agent control reconnect with exponential backoff and same-region Hub selection. Persist sequence, applied version, last successful backend heartbeat and credential state before emitting acknowledgements.
3. Reconcile desired/runtime configuration through Engine Prepare/Commit/Abort, persist per-object results and transaction IDs, and return stable stale/conflict errors.
4. Add upgrade supervisor preflight, bounded drain, signed binary/config/disk checks, compatibility snapshot, health check and automatic rollback. Block rollback after an irreversible local schema migration.

## Verification

- Certificate tests cover local private key generation, SAN mapping, renewal, revocation, expired cert, reconnect and old/new overlap.
- Lost control stream and duplicate messages are idempotent; no ACK precedes durable local commit.
- Upgrade tests cover drain timeout, failed health check, rollback and migration incompatibility.
- Docker and Actions run the same registration/control/upgrade fixture on one SHA.
