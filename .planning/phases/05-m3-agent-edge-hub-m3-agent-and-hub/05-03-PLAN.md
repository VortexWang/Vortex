# Plan 05-03: Grants, usage handoff and bounded autonomy

## Goal

Connect durable Agent/Hub authorization and accounting to the Engine boundary while preserving conservative time, quota, signer_epoch and disk semantics.

## Tasks

1. Implement durable grant/lease records with TTL, source IDs, signer_epoch, path generation, hard deadline and fencing lower bounds. Enforce the 30-second loss transition from the last successful backend heartbeat and a non-extendable autonomy deadline.
2. Implement usage batch ingestion from Engine: persist batch and unknown upper bound before ACKing Agent; persist Hub ledger before Agent ACK in online mode, and ACK locally in autonomy while retaining the batch for handoff.
3. Enforce restricted autonomy: renew existing rules/owned shares/delegated balances only; reject new rules, ports, DNS, registrations and cross-node rebalance. Stop new authorization when time or disk evidence is not trustworthy.
4. Add signer_epoch handoff guards distinct from Engine path generation. Preserve old authorization at its original boundary and freeze unknown liabilities when ownership or closure evidence is missing.

## Verification

- Property tests cover source conservation, duplicate usage, lost ACK, hard deadline, clock uncertainty, quota exhaustion and signer_epoch/path-generation separation.
- Full-disk and SQLite write-error fixtures stop all consumption that would be unrecordable.
- Offline/online transition tests prove no new authority is invented and no old authority is released by timeout or connection switch.
- Docker and Actions execute the same mixed Agent/Hub/Engine fixture and retain raw ledger evidence.
