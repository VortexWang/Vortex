## 注册与凭据

**确认：** 一次性令牌仅首次 CSR 注册；运行证书表达 node_id，boot_id 在运行握手绑定；私钥节点本地生成并受限存储。

### 续期与吊销

备选方案：采用推荐方案；调整方案。

**确认：** 短期证书自动续期；新证书校验成功后退役旧证书；吊销拒绝重连和续期，无无限过期宽限。

## 进程监督与升级

### 进程监督

备选方案：单进程正式接口；分进程 IPC。

**确认：** 单一 vortex-node，正式进程内接口协调；Agent 崩溃进程退出，由 systemd 重启。

### 升级排空

备选方案：有界排空；无限等待；短暂宽限强制关闭。

**确认：** 停止新流，有界排空；超时关闭残余会话再替换。

### 回退与兼容

备选方案：预检及兼容回退；手动回退；原位覆盖。

**确认：** 校验二进制/签名、磁盘和配置兼容性，保留旧二进制与兼容状态快照；健康失败自动回退，不可逆 schema 迁移阻止自动回退。

## SQLite 耐久与磁盘故障

### 耐久级别

备选方案：FULL；NORMAL；动态调整。

**确认：** 账本、授权和回执使用 FULL；对外 ACK 前提交并同步落盘，普通遥测可单独批处理。

### 磁盘故障

备选方案：停止相关消费；只停新流；内存暂存。

**确认：** 满盘/写失败停止新授权与新流，并停止产生无法记账消费的既有流；保留未确认记录，恢复后对账。

### 账本归属

备选方案：独立数据库；共享数据库；仅 Hub 持久化。

**确认：** Agent/Hub 独立 SQLite，通过幂等协议交接，不共享 WAL。

## Hub 自治边界

### 自治起点

备选方案：心跳起算；发现断线起算；无限自治。

**确认：** 最后成功后端心跳计时；连续 30 秒失联进入自治，硬截止为心跳+自治上限，重启不延长。

### 自治范围

备选方案：受限自治；允许新增；允许再平衡。

**确认：** 仅既有规则、逐节点既有份额、已委托额度；禁止新规则/端口/DNS/注册与跨节点再平衡。

### 时间不可信

备选方案：保守停止；未计时消息替代时钟；短 TTL 继续签发。

**确认：** 可信时间未恢复或硬截止不明确，禁止跨绝对边界新授权并停止相关新流。

### 签发代次与路径代次

备选方案：分开管理，原授权保持原边界；自治与恢复强制切换路径代次。

**确认：** 区分 signer_epoch 与路径 generation；恢复时原子关闭旧签发权并转接余量，旧授权在原边界内有效，路径仅在配置变化时切代。

## 账本交接与重放

### 恢复账本交接

备选方案：原子封存和唯一转接；等待全部结清；复制余额异步去重。

**确认：** 先执行吊销与限制；同一 SQLite 事务封存旧前缀至 S，以唯一转接记录将同一委托未签发余量 R 转给后继 epoch；在外授权由原预留覆盖。

### 重放和清理

备选方案：幂等检查点并保留争议记录；任一响应后清理；固定保留期清理所有记录。

**确认：** 前缀与持续尾账按唯一 ID 幂等重放；仅确认检查点推进后清理已结清记录，至少保留 7 天；争议记录持续保留。

### 证据不足

备选方案：冻结并保留证据；超时释放；按 Agent 清单推算释放。

**确认：** 停止相关签发并冻结未知负债，保留证据；控制连接切换或超时本身不能释放资源。

## 激活状态与重启恢复

### Commit 结果未知

备选方案：持久化未知状态并查询；超时 Abort 释放；内存记录重启重做。

**确认：** 发送 Commit 许可前持久化事务和占用；发送后结果未知保持 activation-unknown，查询同一事务，不凭超时释放。

### 节点重启

备选方案：恢复后按授权链激活；复用旧 boot_id 和授权；新 boot_id 立即回收旧占用。

**确认：** 每次启动生成新 boot_id；旧授权仅补报和结算；先恢复账本与可信时间，再 Prepare、取得合法授权、Commit；新 boot_id 不是旧进程已停止的证明。

### 幂等与安全终结

备选方案：持久化幂等与实际状态查询；最后请求覆盖；重复执行定时修复。

**确认：** 按事务 ID 持久化幂等结果；查询持久化 fencing 下限及 Engine 实际代次；冲突转换返回稳定错误，满足安全终结证明后才释放。

### Phase 5 验证边界

备选方案：真实组件加后端协议测试服务；仅状态机单测；提前完整生产后端。

**确认：** 明确标记的后端协议测试服务配合真实 Agent/Hub、SQLite 与 Engine；验证崩溃、满盘、丢回执，同一 SHA 的 Docker 与 Actions 保存证据；生产后端业务闭环留给 Phase 6。
