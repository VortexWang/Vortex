| Agent/Hub renewal -> share authority | renewal request can replay or present stale boot/generation. |

| share authority -> metering/compiler | allocation can over-authorize if snapshot or limits mismatch. |

| T-06-12 | Tampering | activation unknown/handoff | high | mitigate | Ordered handoff, idempotent receipt, unknown retention and status reconciliation before release. |
| T-06-19 | Tampering | dependency/toolchain installs | high | mitigate | Use existing approved modules; no alternate lease library without lock/license review. |
