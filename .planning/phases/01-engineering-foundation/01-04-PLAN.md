## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host/runner to Docker test container | Host resources and Docker daemon are privileged interfaces. |
| GitHub event to workflow | Untrusted pull-request code can execute during CI. |
| Test result to evidence archive | A skipped job or wrong commit can be mistaken for passing verification. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-05 | Elevation of Privilege | Docker network namespace fixture | high | mitigate | Limit capabilities to the isolated test container, avoid host networking and Docker socket mounts, and assert cleanup. |
| T-01-06 | Tampering | GitHub Actions result and artifact | high | mitigate | Use least-privilege permissions, SHA-pinned actions, exact common command and commit-bound artifact metadata. |
| T-01-SC | Tampering | Actions and test container inputs | high | mitigate | Require full action SHAs and a lock-pinned image digest before executing untrusted repository changes. |
</threat_model>
