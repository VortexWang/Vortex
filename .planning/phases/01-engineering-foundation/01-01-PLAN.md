<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Package/image/action source to baseline | External registries and repositories provide untrusted version, integrity and license metadata. |
| Candidate manifest to immutable lock | A human-approved digest is required before the baseline becomes authoritative. |
| Repository paths to historical evidence status | File existence alone does not establish an authentic review or freeze record. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | dependency/image/action baseline | high | mitigate | Require source URL, immutable digest/checksum, license evidence and a blocking user confirmation of the candidate manifest hash. |
| T-01-02 | Spoofing | historical review/evidence status | high | mitigate | Require the original record and evidence link; a new register entry cannot make missing historical evidence verified. |
| T-01-SC | Tampering | package installation and CI tool resolution | high | mitigate | Install only exact approved entries; reject floating tags and unknown/disallowed licenses before build or release. |
</threat_model>
