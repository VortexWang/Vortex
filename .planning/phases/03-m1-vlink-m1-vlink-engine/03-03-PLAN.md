<task type="auto">
<name>Implement deterministic OPEN validation</name>
<files>engine/vlink/open.go, engine/vlink/open_test.go</files>
<action>Validate local rule revision/path generation, peer node membership, hop index, visited list, network type, original-client bounds, active configuration, and runtime authorization. At a platform execution point, require valid rate/connection shares and remaining billing authorization whose `billing_snapshot_id` and coefficient match the session and whose runtime authorization allows that snapshot; on other path nodes require runtime authorization and segment permission without requiring execution-point shares/billing; apply the MTR-011 self-hosted exemption. Reject stale/no-route/unauthorized/quota/rate/connection/target classes with stable codes and correlation audit events; do not expose target or internal policy details. Exclude visited nodes and return `no_route` when no locally configured eligible next hop exists, without implementing multi-hop scheduling (ENG-022, ENG-024; D-13, D-14, D-17).</action>
<verify>Test every rejection class, stale revisions, own node in visited, invalid hop, missing local snapshot, quota denial, and audit correlation. Assert no control-plane callback occurs.</verify>
<done>OPEN is a pure local decision with stable errors and complete rejection audit coverage.</done>
</task>
<task type="auto">
<name>Enforce local target restrictions</name>
<files>engine/vlink/target.go, engine/vlink/open_test.go</files>
<action>Select downstream targets only from injected local runtime configuration. Reject peer-provided target fields, private/reserved destinations, invalid addresses, and DNS resolution that changes to a forbidden address; make resolution and validation occur before dialing and record only safe error classes (D-15).</action>
<verify>Test target omission, private/reserved IPv4/IPv6, malformed names, DNS rebinding fixture, local allowlist, and no target detail in wire errors or metric labels.</verify>
<done>No OPEN can make the Engine dial an arbitrary or newly rebound destination.</done>
</task>
<task type="auto">
<name>Gate UDP DGRAM behind OPEN_OK</name>
<files>engine/vlink/udp.go, engine/vlink/udp_test.go</files>
<action>Require successful OPEN/OPEN_OK before DGRAM. Apply per-stream and aggregate windows; drop and count over-window datagrams; reset and audit unauthorized DGRAM; terminate the UDP session on link loss without opaque replay (D-09, D-11, D-16).</action>
<verify>Test DGRAM before OPEN, after OPEN_ERR, after OPEN_OK, over-window drops, link loss, duplicate datagrams, and accounting hook behavior.</verify>
<done>UDP admission cannot bypass authorization and its failure/retry semantics are explicit.</done>
</task>
