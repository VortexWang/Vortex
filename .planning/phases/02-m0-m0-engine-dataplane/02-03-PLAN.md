<task type="auto">
  <name>Implement UDP client sessions and idle expiry</name>
  <files>engine/relay/udp.go</files>
  <read_first>engine/relay/tcp.go, .planning/phases/02-m0-m0-engine-dataplane/02-CONTEXT.md, .planning/phases/02-m0-m0-engine-dataplane/02-RESEARCH.md</read_first>
  <action>Implement UDP(ctx, listener, target, options, meter) using one upstream connected UDP socket per client address. Default zero IdleTimeout to 60 seconds and reject negative timeout. Refresh activity on client packets and received responses. Expire only the exact session instance currently mapped to the client, close its upstream socket, and verify session identity before returning a response to the listener so stale responses cannot reach a replacement. On cancellation close listener and all upstream sessions, wait for response goroutines, and return the context error. Meter only bytes accepted by each UDP socket write. Keep this implementation standard-library-only and independent of gates/database/control plane.</action>
  <verify>
    <automated>cd engine &amp;&amp; go test -race ./relay</automated>
    <manual>Review session replacement and cleanup locking for stale response delivery and goroutine leaks.</manual>
  </verify>
  <done>UDP relay owns client sessions, defaults idle timeout to 60 seconds, meters successful datagram writes, and closes all owned resources on expiry or cancellation.</done>
</task>
