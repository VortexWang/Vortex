# Plan 02-04: Bounded UDP Admission

<objective>
<goal>Bound per-client UDP session allocation before any session-owned resources are created.</goal>
<purpose>Close the denial-of-service exposure found during Phase 2 verification while preserving routing and cleanup behavior.</purpose>
<output>Configurable global and per-client session limits with deterministic saturation behavior and race-tested resource release.</output>
</objective>

## Tasks

<tasks>
<task type="auto">
<name>Implement pre-allocation session admission</name>
<files>engine/relay/udp.go</files>
<action>Add configurable global and per-client session limits to UDP relay options. Define deterministic behavior for a new session that exceeds either limit, and perform admission before allocating an upstream socket, map entry, response buffer, or goroutine. Ensure expiry and cancellation release each permit once.</action>
<verify><automated>cd engine &amp;&amp; go test -race ./relay</automated><manual>Inspect lock ordering and replacement logic for races and permit leaks.</manual></verify>
<done>Every allocated UDP session owns one permit, rejected clients allocate no session resources, and cleanup releases capacity exactly once.</done>
</task>
<task type="auto">
<name>Cover saturation and permit release</name>
<files>engine/relay/udp_test.go</files>
<action>Add deterministic race-enabled tests for global saturation, per-client saturation, replacement after expiry, cancellation release, and no session allocation on rejection. Use loopback fixtures and short explicit expiry overrides.</action>
<verify><automated>make phase2-engine-check</automated><fails_when>Any limit is exceeded, a rejected client creates resources, capacity is not reclaimed, or a stale response crosses session generations.</fails_when></verify>
<done>Admission and cleanup tests pass in the shared local and Actions test entry.</done>
</task>
</tasks>

## Verification

`go test -race ./relay` must prove no duplicate release, stale response routing, or goroutine leak in the bounded paths. `make phase2-engine-check` is the required wave gate.
