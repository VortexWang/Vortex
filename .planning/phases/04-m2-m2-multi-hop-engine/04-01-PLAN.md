## Goal

Create the first startable runtime boundary: one `vortex-relay` binary with
strict JSON configuration, certificate identity loading and an auditable
in-process accounting adapter.

## Tasks

1. Define a runtime configuration struct and strict decoder against the frozen
   JSON Schema. Reject unknown fields, missing node identity, invalid roles,
   duplicate listeners, invalid peer paths and missing certificate files.
2. Load TLS 1.3 mTLS material and verify the configured node URI SAN using the
   existing VLink identity helpers. Do not add YAML/TOML dependencies.
3. Implement a concurrency-safe memory accounting Gate with stable batch IDs,
   reservation/commit/return/unknown events, bounded JSONL export and invariant
   counters. Unknown outcomes retain the full reserved upper bound.
4. Add `cmd/vortex-relay` flags for config path, role, evidence path and
   readiness endpoint. The process must fail closed on invalid configuration
   and terminate all resources on SIGINT/SIGTERM.

## Verification

- `go test -race ./runtime/... ./engine/...`
- Invalid config and certificate fixtures fail with stable error classes.
- A valid config starts, writes readiness and exits cleanly on signal.
- Accounting tests prove exactly-once resolution and unknown retention.

## Done when

The binary starts with a validated role/config and the accounting adapter can
produce evidence, but no network forwarding claim is made yet.
