## Goal

Run mixed TCP/UDP traffic through the real topology and verify accounting,
fairness, generation changes and failure behavior.

## Tasks

1. Build a deterministic workload with long-lived TCP, 1,200-byte UDP at the
   target rate, sequence/checksum validation and bounded duration.
2. Drive immutable billing snapshots and the in-process adapter through every
   successful write; record reservation churn, queue occupancy, drop classes,
   unknown outcomes and reconciliation results.
3. Exercise path generation change during TCP drain and UDP termination/reopen;
   verify no opaque UDP replay and no stale OPEN acceptance.
4. Make evidence verification fail on missing runtime readiness, missing
   accounting records, checksum/loss errors, bypass evidence or malformed
   metadata. `environment-limited` is not a success status.

## Verification

- `make phase4-runtime-mixed BACKEND=docker`.
- Same workload on native Ubuntu.
- `go test -race ./runtime/... ./engine/...`.
- Evidence checker proves accounting invariants and resource cleanup.

## Done when

The qualification command cannot report success unless the real three-relay
runtime and complete accounting evidence are present.
