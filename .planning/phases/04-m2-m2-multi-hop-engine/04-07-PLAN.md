# Plan 04-07: Fail-Closed Source Authorization

## Goal

Close G-04-01 so ordinary runtime configuration cannot silently run the Phase 4
tracer without funded source authorization or with synthesized billing/share
rights. Keep the existing local qualification topology runnable only through an
explicit qualification-only mode. This closes the unsafe default boundary; it
does not provide durable Agent/Hub authority or qualify NFR-044.

## Threat Model

<threat_model>
- T-04-11: an operator starts a runtime without funded source authorization and the process forwards payload as if authorized; default-deny configuration and a conspicuous qualification-only mode mitigate.
- T-04-SC: Engine remains process-local and database-free; qualification-only mode must not be mistaken for funded production authorization.
</threat_model>
