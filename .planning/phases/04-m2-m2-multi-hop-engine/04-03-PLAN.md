## Goal

Create a real five-process qualification topology using the same manifest for
Docker Compose and native Linux launch.

## Tasks

1. Define a topology manifest containing source, relay-1, relay-2, relay-3 and
   destination identities, peer addresses, authorized path, rule revision and
   generation. Hash the normalized manifest for evidence.
2. Add deterministic local certificate generation for the five node IDs and
   explicit trust/revocation configuration. Do not commit private keys.
3. Add Compose services and a native launcher that invoke the same runtime
   binary/configuration and expose readiness/health checks.
4. Add an end-to-end TCP payload/checksum workload that proves all three relay
   hops were traversed and bypass attempts fail.
5. Ensure launcher shutdown removes child processes, sockets and temporary
   credentials.

## Verification

- `make phase4-runtime-smoke BACKEND=docker`.
- Same command with `BACKEND=native` on Ubuntu 24.04.
- Inspect topology digest, visited-hop audit and clean resource report.
- Deliberately forge OPEN path/target and assert stable rejection.

## Done when

The five-process runtime starts from one manifest in both backends and proves
an authorized three-relay TCP route before any throughput test is allowed.
