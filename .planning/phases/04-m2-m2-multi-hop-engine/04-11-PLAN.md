## Goal

After runtime authorization and early-DATA correctness are wired, execute the
controlled D-04 experiments and formal NFR-003/NFR-005 qualification workflow.
This plan records results; it does not assume the candidates pass.

## Implementation Detail

1. Add workload matrix support for block sizes 64/256/1024 KiB, grant targets
   10/30/60 seconds with the 8 MiB floor, and waterlines 20/30/50 percent.
   Record one-factor changes, issuer wait p50/p95/p99, merge rate, occupancy,
   unknown upper bounds and conservation per source.
2. Run short-flow, 16-stream long-flow and TCP plus actual 100 Mbps UDP cases
   with the same authorization and route topology. Preserve failed attempts and
   actual offered load; requested rate alone is never qualification evidence.
3. Require eligible native Linux resource/link isolation, 60-second warmup and
   three 300-second trials plus independent TLS comparison. Keep Docker and
   hosted Actions as reproducibility/regression evidence.
4. Produce a reviewed parameter table and update the qualification matrix only
   after all gates pass. Leave candidates unlocked when any gate is absent.

## Verification

The qualification command must return non-zero for missing runtime/accounting evidence, inadequate host isolation, incomplete trials, or conservation failure. Archive raw workload, metadata, manifests and checksums for each host and SHA.
