## Goal

Make native and Actions qualification run the same real topology and produce
reviewable performance evidence with hard failure gates.

## Tasks

1. Replace benchmark smoke with a health-gated command that starts the five
   processes, runs same-path and three-relay benchmarks, then runs mixed load.
2. Measure mux/pool first-byte latency, throughput ratio, UDP loss, queue/drop
   counters and accounting reconciliation from the same config digest.
3. Pin Actions to the same Make target and upload raw logs, normalized report,
   topology manifest, config digest and checksums.
4. Keep D-04 values as candidates until the report is reviewed; do not promote
   benchmark output automatically.
5. Produce new UAT and verification documents only after all five plans execute.

## Verification

- Local native Ubuntu run on a clean SHA.
- Local Docker run with the same SHA and manifest.
- GitHub Actions run on the same SHA.
- Report exits non-zero for missing runtime/accounting evidence and records
  explicit qualification verdicts.

## Done when

Phase 4 has a reproducible runtime-backed qualification path. NFRs are marked
passed only when their topology, workload and ratio conditions are satisfied;
otherwise the new verification remains explicitly incomplete.
