## Goal

Remove the known OPEN_OK extra-wait behavior for authorized TCP without
weakening authorization, then close the finite NFR-006/NFR-007 coverage gaps
with controlled runtime evidence.

## Implementation Detail

1. Define bounded pre-OPEN DATA buffering and authorization reservation rules;
   discard/reset on OPEN rejection, timeout, stale generation or downstream
   failure. Keep UDP strictly gated after OPEN_OK.
2. Add stream/link timeline fields for OPEN sent, authorization complete,
   first DATA sent, first target byte and reset. Cover pool reuse, mux and new
   link separately.
3. Expand probes and fixtures across identity, certificate/node mapping,
   visited nodes, hop index, target omission, rule/path revision, generation,
   replay and bypass combinations; store the complete included/excluded matrix.
4. Run controlled RTT scans and verify no target payload is written before the
   corresponding authorization event.

## Verification

Run race tests for VLink/link/relay, forged/bypass probes, Docker topology comparisons and Actions on the same SHA. Any unauthorized target byte, unbounded buffer, or missing timeline blocks the plan.
