## Goal

Move the existing finite `PolicyBoundary` and `CreditBook` behavior into the
source runtime execution point without turning the adapter into a durable
authority. Preserve the Phase 4 process-local injection boundary and produce
runtime evidence for NFR-039 and the implementable portion of NFR-044.

## Implementation Detail

1. Add explicit config fields for injected clock bounds, issuer timeout,
   policy window and snapshot/path coefficient bindings. Reject incomplete or
   contradictory values before listeners start.
2. Construct the policy-aware Gate in `vortex-relay` and pass it to source
   TCP/UDP bridges. Existing sessions retain their immutable snapshot; new
   sessions use only the active revision. Missing, stale, unknown or late
   authorization remains reserved and cannot release funds by elapsed time.
3. Add runtime tests for exact-T switching, uncertainty pause/recovery, hard
   deadline, issuer timeout, late grant isolation, coefficient conversion and
   per-source conservation across TCP/UDP and path changes.
4. Add a deterministic Docker/Actions fixture and evidence checker recording
   source key, snapshot, grant state, used, unknown and held bytes. Mark the
   adapter non-authoritative in metadata.

## Verification

`cd engine && go test -race ./runtime/accounting ./runtime/config ./runtime/relay ./cmd/vortex-relay`; `DOCKER_CONTEXT=orbstack make phase4-m2-check`; the matching Actions workflow must pass on the same clean SHA. Any missing authority, conservation mismatch or target write before authorization fails the check.
