## Goal

Compose the existing VLink APIs into a supervised single-hop runtime that can
accept links, authorize OPEN locally and bridge TCP/UDP resources without
violating Engine boundaries.

## Tasks

1. Implement link listener/dialer supervision with TLS 1.3, HELLO generation,
   reconnect backoff, liveness polling and bounded shutdown.
2. Implement relay stream handling using `MuxLink.Accept` and
   `AuthorizeRemote`; use `OpenPolicy` for every hop and never trust an OPEN
   target address supplied by a peer.
3. Bridge TCP with half-close preservation and successful-write accounting.
4. Bridge UDP only after OPEN/OPEN_OK, using `UDPAdmission` and the existing
   bounded scheduler; classify queue/window/downstream drops.
5. Add generation admission and drain callbacks so stale generations reject
   new OPEN while existing TCP streams drain.

## Verification

- Single-hop TCP half-close and response test.
- Unauthorized, stale-generation and forged-target OPEN tests.
- UDP OPEN-before-DGRAM, bounded-drop and link-close cleanup tests.
- `go test -race ./runtime/... ./engine/...` with goroutine/FD cleanup checks.

## Done when

Two runtime processes can establish one authenticated VLink and forward TCP
and UDP through the existing Engine semantics with deterministic cleanup.
